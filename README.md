# Multimodal RAG System

این پروژه یک دستیار هوشمند برای کار با فایل‌های PDF است. کار اصلی برنامه این است که کاربر یک فایل PDF آپلود می‌کند و بعد می‌تواند درباره محتوای آن سؤال بپرسد. سیستم تلاش می‌کند جواب‌ها را بر اساس متن و همچنین بخش‌های تصویری داخل PDF، مثل شکل‌ها، نمودارها و جدول‌ها ارائه دهد.

در واقع این پروژه یک نسخه ساده از RAG چندوجهی است؛ یعنی فقط به متن سند توجه نمی‌کند، بلکه صفحه‌های PDF را به تصویر هم تبدیل می‌کند تا مدل بتواند محتوای بصری سند را هم بررسی کند.

## قابلیت‌های پروژه

- آپلود فایل PDF توسط کاربر
- استخراج متن از صفحه‌های PDF
- تقسیم متن به بخش‌های کوچک‌تر برای پیدا کردن جواب بهتر
- تبدیل صفحه‌های PDF به تصویر
- ارسال متن و تصویر به مدل Gemini
- پاسخ دادن به سؤال‌های کاربر بر اساس محتوای فایل
- رابط کاربری ساده با Streamlit

## ابزارها و کتابخانه‌های استفاده‌شده

- Python
- Streamlit
- PyMuPDF
- Google GenAI SDK
- Gemini Flash

## نحوه اجرا

برای اجرای پروژه، اول کتابخانه‌های موردنیاز را نصب کنید:
```bash
pip install -r requirements.txt

بعد برنامه را با دستور زیر اجرا کنید:

bash
streamlit run main.py

## تنظیمات API

برای استفاده از این برنامه باید یک API Key معتبر از Google Gemini داشته باشید. این کلید در کد برنامه قرار می‌گیرد تا ارتباط با مدل برقرار شود.

## نکته مربوط به اتصال

در فایل `main.py` بخشی برای تنظیمات اتصال و پراکسی در نظر گرفته شده است. این تنظیمات مربوط به سیستم توسعه‌دهنده پروژه است و ممکن است روی سیستم‌های دیگر نیاز به تغییر داشته باشد.

اگر اتصال اینترنت یا VPN شما در سطح سیستم‌عامل فعال باشد، ممکن است لازم باشد بخش تنظیمات پراکسی را تغییر دهید یا کامنت کنید.
