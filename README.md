# Multimodal RAG System
این پروژه یک دستیار هوشمند مبتنی بر معماری RAG چندوجهی است که قادر به درک همزمان متن و تصویر از اسناد PDF می‌باشد.

## ابزارها
* Python
* Streamlit
* LlamaIndex
* Google Gemini 1.5 Flash

## نکته فنی
به دلیل محدودیت‌های شبکه‌ای و تحریم‌ها، ماژول مدیریت ترافیک و پراکسی اختصاصی جهت ارتباط پایدار با سرورهای گوگل در سورس‌کد (فایل main.py) پیاده‌سازی شده است.
## نکته مهم
نکته جهت تست و اجرای محلی (Local Run): پورت 2081 که در فایل main.py تنظیم شده، مربوط به پراکسی سیستم توسعه‌دهنده است. جهت اجرای موفق پروژه روی سیستم خودتان، لطفاً شماره پورت را با تنظیمات شبکه محلی خود جایگزین نمایید و یا در صورت استفاده از VPN در سطح سیستم‌عامل، آن دو خط را کامنت کنید.
