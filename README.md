# Multimodal RAG System

این پروژه یک برنامه ساده برای پرسش و پاسخ از روی فایل‌های PDF است. کاربر می‌تواند یک فایل PDF داخل برنامه آپلود کند و بعد درباره محتوای آن سؤال بپرسد. برنامه هم سعی می‌کند با توجه به متن فایل و تصویر صفحه‌ها، جواب مناسب بدهد.

ایده اصلی پروژه این است که بعضی از اطلاعات داخل PDF فقط به صورت متن نیستند. خیلی وقت‌ها شکل‌ها، جدول‌ها، نمودارها یا حتی ظاهر صفحه هم می‌توانند برای جواب دادن مهم باشند. به همین دلیل در این پروژه علاوه بر استخراج متن، صفحه‌های PDF به تصویر هم تبدیل می‌شوند تا مدل بتواند بخش‌های تصویری سند را هم بررسی کند.


## امکانات پروژه

- آپلود فایل PDF
- استخراج متن از صفحه‌های PDF
- تقسیم متن به بخش‌های کوچک‌تر
- پیدا کردن بخش‌های مرتبط با سؤال کاربر
- تبدیل صفحه‌های PDF به تصویر
- ارسال متن و تصویر به مدل Gemini
- پاسخ دادن به سؤال‌های کاربر بر اساس محتوای فایل
- رابط کاربری ساده با Streamlit

## روند کلی برنامه

برنامه به طور کلی در سه مرحله کار می‌کند:

### 1. استخراج متن و تصویر

بعد از اینکه کاربر فایل PDF را آپلود می‌کند، متن هر صفحه با استفاده از کتابخانه `PyMuPDF` استخراج می‌شود. در کنار آن، هر صفحه PDF به تصویر هم تبدیل می‌شود تا اگر داخل صفحه جدول، نمودار یا شکل وجود داشت، مدل بتواند آن را هم بررسی کند.

### 2. بخش‌بندی و پیدا کردن متن مرتبط

متن استخراج‌شده به بخش‌های کوچک‌تر تقسیم می‌شود. وقتی کاربر سؤال می‌پرسد، برنامه بخش‌هایی از متن را که از نظر کلمات به سؤال نزدیک‌تر هستند انتخاب می‌کند.

### 3. تولید پاسخ با Gemini

در مرحله آخر، متن‌های مرتبط همراه با تصویر صفحه‌های مربوطه برای مدل Gemini فرستاده می‌شوند. مدل با توجه به متن و تصویر، پاسخ نهایی را تولید می‌کند.

## نصب و اجرا

اول پروژه را دریافت کنید:
```bash
git clone YOUR_REPOSITORY_URL
cd YOUR_REPOSITORY_NAME

بعد کتابخانه‌های موردنیاز را نصب کنید:

bash
pip install -r requirements.txt

برای اجرای برنامه از دستور زیر استفاده کنید:

bash
streamlit run main.py

بعد از اجرا، برنامه معمولاً به صورت خودکار در مرورگر باز می‌شود. اگر باز نشد، می‌توانید این آدرس را در مرورگر وارد کنید:

text
http://localhost:8501

## تنظیم API Key

برای اینکه برنامه بتواند به مدل Gemini وصل شود، باید یک API Key معتبر داشته باشید.


اگر از فایل secrets استفاده می‌کنید، داخل پروژه این مسیر را بسازید:

text
.streamlit/secrets.toml

و داخل آن API Key را به این شکل قرار دهید:

toml
GOOGLE_API_KEY = "YOUR_API_KEY"
