# سیستم پرسش و پاسخ هوشمند چندوجهی از اسناد PDF

سلام 
این پروژه یک سیستم ساده  برای پرسش و پاسخ از روی فایل‌های PDF است.

در این برنامه، کاربر می‌تواند یک فایل PDF آپلود کند و بعد درباره محتوای آن سؤال بپرسد. سیستم تلاش می‌کند با کمک متن صفحات و همچنین تصویر صفحات PDF، پاسخ مناسب‌تری تولید کند.

این پروژه برای درس پردازش زبان طبیعی پیاده‌سازی شده است.

---

## امکانات پروژه

- آپلود فایل PDF
- استخراج متن صفحات PDF
- تبدیل صفحات PDF به تصویر برای بررسی بهتر شکل‌ها و نمودارها
- پرسش و پاسخ درباره محتوای فایل
- استفاده از مدل Gemini برای تولید پاسخ
- رابط کاربری ساده با Streamlit
- پشتیبانی از زبان فارسی در محیط برنامه

## تنظیم API Key

برای استفاده از مدل Gemini، باید API Key داشته باشید.

داخل پوشه پروژه، یک پوشه به نام `.streamlit` بسازید.  
داخل آن یک فایل به نام `secrets.toml` ایجاد کنید.

مسیر فایل باید این‌طوری باشد:

text
.streamlit/secrets.toml

داخل فایل `secrets.toml` این مقدار را قرار دهید:

toml
GEMINI_API_KEY = "your_api_key_here"

به جای `your_api_key_here` باید کلید API خودتان را قرار دهید.

نکته مهم:  
فایلی که داخلش کلید API دارد را داخل گیت هاب قرار ندادم.

## اجرای برنامه

بعد از نصب کتابخانه‌ها و تنظیم API Key، برنامه را با دستور زیر اجرا کنید:

بعد از اجرا، برنامه  در مرورگر با آدرس زیر باز می‌شود:

text
http://localhost:8501

## نکته درباره مدل Gemini

در فایل مدل به صورت زیر تنظیم شده است:

python
MODEL_NAME = "gemini-flash-latest"

اگر این مدل برای شما در دسترس نبود یا خطای مدل دریافت کردید، می‌توانید آن را به یکی از مدل‌های زیر تغییر دهید:

python
MODEL_NAME = "gemini-1.5-flash"

یا:

python
MODEL_NAME = "gemini-2.0-flash"

## توضیح کوتاه درباره روش پروژه

این پروژه از ایده Multimodal RAG استفاده می‌کند.

یعنی ابتدا محتوای PDF پردازش می‌شود. متن صفحات جدا می‌شود و صفحات PDF هم به تصویر تبدیل می‌شوند. بعد وقتی کاربر سؤال می‌پرسد، بخش‌های مرتبط از متن انتخاب می‌شوند و همراه با تصاویر مرتبط برای مدل Gemini ارسال می‌شوند تا پاسخ نهایی تولید شود.

 این نسخه، به شکل ساده و قابل فهم پیاده‌سازی شده و بر اساس هم‌پوشانی کلمات بین سؤال کاربر و متن صفحات کار می‌کند.
